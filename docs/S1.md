## What the evidence establishes

Baseline: 82 mypy errors and 77 ruff findings were reproduced. Repaired code now
passes strict mypy (30 source files), ruff, and all 23 tests on clean Linux Python
3.11. The exact pinned CI install ran, the editable package built, and the Docker
image built. Actual app-container requests observed degraded health with both
pipeline-ready flags false and HTTP 503 for an unconfigured query. This confirms
the supported unconfigured boundary, not working Azure search or generation.
Coverage was 67% (764 statements, 254 missed); low-coverage paths remain visible.

The repairs include the packaging backend, import/API schema drift, real async
retrieval and circuit-breaker awaits, refreshing Azure token-provider callbacks,
Search SDK schema/upload result types, and missing configuration checks. Missing
embeddings are omitted, not fabricated as zero vectors. Generation failure reports
degraded status and elapsed time. PDF/DOCX/XLSX placeholder extraction is removed;
only TXT/basic HTML are implemented. API metadata may still describe unsupported
extensions; that does not make a binary parser available.

Tokenizer preparation is explicit, bounded and SHA-256 checked. Runtime fails
when the cached asset is absent/corrupt instead of downloading implicitly or using
a fake tokenizer. Unicode chunk windows preserve complete text, make progress and
respect token limits. Tests block external Python socket/DNS use except loopback;
this is a test guard, not a security sandbox. Tests use explicit Azure/model mocks.
CI and Docker use requirements-ci.lock; declared broad dependency ranges remain
in requirements.txt/pyproject.toml and require deliberate lock regeneration.
No ignore/skip/xfail/noqa/type-ignore was added to reach green.

## Limits

Azure deployment, credentials, live indexing/search/generation, financial answers,
retrieval quality, real provider retry faults and production readiness are unproven.
The breaker does not establish concurrent single-probe half-open behavior. Azure
Search calls are synchronous inside async methods. Semantic reranking currently
re-queries the index rather than reranking only the supplied hybrid candidate set.
SDK/JSON dictionaries remain dynamic at external boundaries. Basic HTML extraction
is not table/layout-aware. The broad held-out benchmark B01 remains deferred.
S2 provides the corpus manifest and S5 the separate evaluation harness.
